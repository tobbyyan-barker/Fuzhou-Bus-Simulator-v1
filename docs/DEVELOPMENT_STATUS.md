## 三、下一阶段目标（按用户既定方向）

### 目标 1：真实客车模型

- **现状**：虚构品牌「闽通 MT-10」，图元拼装模型（无版权风险）。
- **方向**：引入高保真客车模型。
- **合规要求（红线）**：
  - 真实品牌（宇通/金龙/比亚迪等）在获得授权前**禁用**；
  - 若使用第三方模型：必须确认许可允许游戏发布，登记 `docs/ASSET_LICENSES.md`（来源/作者/许可/署名），打破「零外部素材」原则时需在 README 同步修订；
  - 自建高模（Blender 建模）为无风险路线。
- **技术要点**：保持 `VehicleBody3D + 6×VehicleWheel3D` 物理骨架不变，只换可视 Mesh；碰撞形状同步调整；`data/vehicles/` 新增 `.tres` 支持多车型并存。

### 目标 2：福大（福州大学）附近真实道路

- **现状**：虚构「鼓山测试场」2.47 km 程序化路线（未使用任何真实地理数据）。
- **方向**：以福州大学周边真实路网为基础的地图。
- **合规要求（红线）**：
  - 若采用 OpenStreetMap 数据：遵守 **ODbL 许可**（署名 + 同类许可共享），README 与 ASSET_LICENSES 登记来源与许可；
  - 中国地图内容需注意测绘合规（位置精度偏移处理、不含敏感区域），必要时咨询法务后再上线发布；
  - 路名/地名如实标注即可，不虚构。
- **技术要点**：`route_manager.gd` 已程序化生成路线并暴露双车道 API；真实路网导入需要：路网数据 → 折线/曲线转换 → 车道中心线生成 → 红绿灯/站点数据挂接；建议先做小范围（福大怡山校区周边 1–2 km）验证管线，再扩展。
