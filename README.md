# 福州客车模拟器 · 第一版 v1（Fujian Bus Simulator）

基于 **Godot 4.7.2**（GDScript 2.0）开发的 Windows 平台 3D 国产客车驾驶模拟游戏 MVP。
参考《欧洲卡车模拟 2》的驾驶体验方向，**全部代码、美术、音效均为原创程序化生成，零外部素材**（无版权风险）。

- 车型：虚构品牌 **闽通 MT-10** 大客车（6 轮、自动挡 D/N/R、数据驱动参数）
- 地图：鼓山测试场，约 **2.47 km** 程序化路线（直道 → 缓弯 → 8% 坡道 → 长直道 → 终点巴士站）
- 玩法：沿右侧车道行驶，遵守红绿灯、礼让对向车流、超越同向慢车，最终在总站站牌 **5 m 内停稳 3 秒**完成任务

## 一、用法

### 1. 环境要求

- Windows 64 位
- Godot **4.3+**（开发验证版本：4.7.2-stable 官方便携版，[下载地址](https://github.com/godotengine/godot/releases)）
- 无需安装任何依赖或插件，克隆即玩

### 2. 启动游戏

**方式 A：命令行（推荐）** —— `Win+R` 输入 `cmd`，粘贴回车（路径含中文，引号不能省）：

```
"<Godot可执行文件路径>" --path "<本项目路径>"
```

**方式 B：Godot 项目管理器** —— 打开 Godot → Import → 选择本项目的 `project.godot` → F5 运行。

### 3. 操作键位

| 按键 | 功能 |
|---|---|
| W / S | 油门 / 刹车（踏板渐变，轻点可控） |
| A / D | 左转 / 右转（侧向加速度限角，任何车速满舵不侧翻） |
| C / Q | 循环切换视角：跟车（默认）→ 车顶 → 左侧 → 右侧 → 第一人称驾驶舱，再按回到跟车 |
| R / N | 倒挡 / 空挡 |
| 空格 | 手刹（紧急停车：速度立即清零，HUD 右上角红色感叹号） |
| H | 喇叭（程序化合成双音气喇叭，按住持续鸣笛） |

**任务目标**：开到终点巴士站，站牌 5 m 内停稳 3 秒，HUD 提示到站完成。

### 4. 附加模式

```
# 自动驾驶演示（AI 自己开完全程：等红灯、跟车、借道超车、进站）
"<Godot路径>" --path "<项目路径>" -- --auto

# 性能基准测试（600 帧采样，输出平均帧时间）
"<Godot路径>" --path "<项目路径>" -- --bench
```

### 5. 运行自动化测试（headless，无需打开窗口）

```
# AC 验收测试套件（6 项）
"<Godot路径>" --headless --path . res://tests/test_mvp.tscn

# 手感/功能量化诊断（14 项）
"<Godot路径>" --headless --path . res://tests/feel_check.tscn
```


## 二、截止目前的优化历程（v0.1.0 → v0.1.6）

每一轮优化均由**试驾反馈或自动化测试**驱动，改动后全量回归（AC 6 项 + 手感诊断 13 项 + 自动驾驶全路线闭环）。

### v0.1.0 —— MVP 首发（可驾驶 + 可验收）

交付：MT-10 客车（VehicleBody3D 六轮物理）、2.47 km 测试路线、双视角、HUD、到站任务、7 项量化验收标准（AC1–AC7）。
过程中解决的核心问题：

1. **客车穿地坠落**：Godot 悬挂力公式随质量放大但 `suspension_max_force` 不随质量缩放，叠加悬挂几何零余量 → 车轮射线永久失效。修复：底盘碰撞箱兜底 + 悬挂阻尼调至近临界 + 增大几何余量。
2. **车辆"倒着开"**：Godot VehicleWheel 前向轴（车轴×法线）与建模朝向相反，正驱动力推向车尾。修复：驱动力取负 + 朝向对齐。
3. **headless 测试假死**：协程调用不存在的 API 导致静默挂起（表象为超时而非报错）。修复：看门狗帧计数器 + `--check-only` 静态校验。

### v0.1.1 —— 驾驶手感（三轮试驾反馈闭环）

| 用户反馈问题 | 解决方案 |
|---|---|
| 转向过灵：轻点即近侧翻 | 转向重做为**侧向加速度预算**（δ_max = atan(a·L/v²)）：任何车速满舵的转弯力恒定且低于侧翻阈值；低速保留大角度（38° 泊车可用） |
| 刹车过灵：轻点即刹停 | 刹车改**踏板渐变**（踩 1.5/s、松 6/s）+ 制动力逐轮调低，轻点掉速从 11.5 → 5.5 km/h |
| 倒车几秒后自己跳回 D 挡 | 真 bug：倒挡误操作保护误用绝对速度（倒车加速被误判为高速行驶）。修复：改用带符号前向速度判定，纯倒车永不触发 |
| 倒挡时视角反馈弱 | HUD 挡位变红 + 倒车横幅 + 车尾射线**倒车雷达**（12 m 探测，实时显示障碍距离） |

配套：车身重心 0.95→0.75 m、轮距加宽至 2.4 m（侧翻阈值提高 36%）。

### v0.1.2 —— 三项体验功能

- **手刹 = 紧急停车**：速度立即清零（38.8 km/h → 0.6，0.1 s），HUD 右上角红色感叹号警示。
- **H 键喇叭**：运行时合成双音气喇叭（350+440 Hz PCM，零外部音频文件）。
- **对向车道车流**：6 辆对向车（含轿车/货车/电动自行车）带真实碰撞。
- 修复：客车改走**右侧车道**（此前压中央虚线行驶，会与对向车剐蹭）。
- 修复隐藏炸弹：交通车入物理空间时先以原点姿态注册再移位，与出生点客车重叠一帧 → 分离冲量把客车炸飞至 64000 km/h。修复原则：**先定位、再入树**（AC2 测试当场捕获）。

### v0.1.3 —— 双向交通 + 红绿灯

- **右侧车道同向车流**（2 轿车 + 1 货车 + 2 电动车）：交通车感知红绿灯（红灯前曲线减速停在停车线）、同车道跟车防追尾。
- **双侧红绿灯**：3 处灯位、两侧灯体、秒数倒计时、路面停车线；绿 25 s / 黄 3 s / 红 20 s，相位错开。
- **红灯提醒双通道**：HUD 红色横幅（距离 + 剩余秒数）+ **车内 TTS 语音播报**（"前方红灯，请注意减速停车" / "绿灯亮起，请起步"）。
- 自动驾驶升级：速度匹配跟车（稳定车距 29 m）+ 慢车借对向车道超车（对向净空条件满足才超、总站与红灯前不超）。
- 修复：初版"刹停-再起步"式跟车在弯道剐蹭电动车后卡死 30 s，重写为速度匹配 + 超车后整体反而提速 30 s。

### v0.1.6 —— 五视角循环

- C / Q 键升级为**五视角循环**：跟车（默认）→ 车顶 → 左侧 → 右侧 → 第一人称驾驶舱 → 回到跟车。
- 车顶/左侧/右侧三个新视角为**刚性绑定**（随车身俯仰侧倾，画面如固定在车上的机位），参数（位置偏移、注视距离、FOV 等）全部 Inspector 可调、实时生效。
- 新视角相机由代码生成，场景文件零改动；切换仍只改 `Camera3D.current`，对车辆物理实测零扰动（0.00 m/s）。
- 新增 feel_check 断言 `FEEL_VIEW_CYCLE`（C/Q 双键绑定、5 键顺序、回环）并扩展 `FEEL_CAB_CAM`（车顶高于车身、左右分居两侧几何校验）。

### v0.1.5 —— 第一人称视角规格化 + 测试稳定性

- 视角切换新增 **Q 键**（保留 C 键）；启动默认第三人称跟车。
- 驾驶舱相机参数拆分为 Inspector 可调项（`mt10.tres`）：`cab_eye_offset`（左右/高度/前后偏移）与 `cab_fov_deg`（视场角），调整实时生效；切换经实测对车辆物理零扰动。
- 修复测试稳定性问题：交通布局洗牌误用全局随机导致测试间歇性失败；传送清场逻辑会把同向车"清"进终点进站通道挡住进站路径。修复后 AC 套件连跑 3 次全部通过、结果完全确定。

### v0.1.4 —— 倒计时牌视觉修复

- 用户截图反馈数字占半屏：根因是 Label3D 开了 `fixed_size` + `billboard` + 无深度测试（屏幕空间固定大小，无视距离、穿透遮挡）。
- 修复为**世界空间真实尺寸**（约 0.4 m 高）挂装在灯杆上的小面板，形成"立杆 + 顶部三色灯箱 + 杆上倒计时牌"的真实路侧结构：远处自然变小、正常遮挡、正对来车可读。
